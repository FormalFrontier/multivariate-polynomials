## Module `MultivariatePolynomials.IdealOfVars`

> # The variable ideal in infinitely many variables
>
> This module proves that the ideal generated by all variables in a multivariate
> polynomial semiring is not finitely generated when the variable type is
> infinite and the coefficient semiring is nontrivial.
>
> Suppose finitely many polynomials generate the ideal. Their variables form a
> finite set; evaluate those variables at zero and a fresh variable at one. Each
> generator has zero constant coefficient, so evaluation annihilates the proposed
> span, but evaluates the fresh variable to one, contradicting nontriviality.
> This argument requires neither additive inverses nor countably many variables.

[Module source](../MultivariatePolynomials/IdealOfVars.lean)

### MvPolynomial.idealOfVars_not_fg

```lean
theorem MvPolynomial.idealOfVars_not_fg (k : Type u_1) (σ : Type u_2) [CommSemiring k] [Nontrivial k] [Infinite σ] : ¬(idealOfVars σ k).FG
```

The ideal generated by all variables is not finitely generated when the
variable type is infinite and the coefficient semiring is nontrivial.
