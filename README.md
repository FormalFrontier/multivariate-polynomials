# Multivariate polynomials

A Lean library proving that the ideal generated by all variables in a
multivariate polynomial semiring is not finitely generated when the coefficient
semiring is nontrivial and the variable type is infinite. The public theorem is
`MvPolynomial.idealOfVars_not_fg`, the negative companion to mathlib's
finite-variable theorem `MvPolynomial.idealOfVars_fg`.

If finitely many polynomials generated the variable ideal, the union of their
variable supports would be finite. Evaluate every used variable at zero and
every other variable at one. The proposed generators have zero constant
coefficient and evaluate to zero, but a fresh variable lies in their span and
evaluates to one: a contradiction. No field, ring, domain or countability
assumption is needed. Coefficient and variable types have independent universes.

Nontriviality and infinitude are essential: the zero semiring and finite variable
types do not satisfy this conclusion. The theorem includes the empty proposed
generator set. It concerns the variable ideal only, not a general ideal or the
complete short-exact-sequence counterexample that motivated the project.

## Public interface and example

Use `import MultivariatePolynomials` for the aggregate interface, or
`import MultivariatePolynomials.IdealOfVars` for the direct theorem module.
Neither requires access to private declarations. The following complete native
module is stored verbatim in [Test/ReadmeExample.lean](Test/ReadmeExample.lean)
and compiled by the default test target. Its named declarations are private
clients, not additional library API.

```lean
/-
SPDX-License-Identifier: Apache-2.0
Authors: Formal Frontier Agents
-/
module

import MultivariatePolynomials.IdealOfVars

/-! # A generic variable-ideal client and its rational specialization -/

universe u v

private theorem readmeVariables (k : Type u) (σ : Type v)
    [CommSemiring k] [Nontrivial k] [Infinite σ] :
    ¬ (MvPolynomial.idealOfVars σ k).FG :=
  MvPolynomial.idealOfVars_not_fg k σ

private theorem readmeRationals : ¬ (MvPolynomial.idealOfVars ℕ ℚ).FG :=
  MvPolynomial.idealOfVars_not_fg ℚ ℕ
```

## Reproduce

The project pins Lean `v4.34.0-rc2`, mathlib
`83abb3e776bdefcbc447a1e44d0debe4010039e5`, and nine resolved external packages.
There is no dependency on another Formal Frontier deliverable. Fetch the
matching precompiled mathlib cache in this checkout before building:

```sh
lake exe cache get
lake --wfail build
lake --wfail build MultivariatePolynomials MultivariatePolynomialsTests
lake env lean -DwarningAsError=true Test/ReadmeExample.lean
lake env lean -DwarningAsError=true Test/IdealOfVars.lean
lake env lean -DwarningAsError=true Test/LeafImport.lean
lake env lean Test/Axioms.lean
python3 -B scripts/test_generate_api.py
```

The default build includes both production modules and all four test/example
modules. Tests are not imported by the public aggregate. Generic, rational and
unequal-universe clients exercise intended public imports. `Test/Axioms.lean`
prints the public theorem's transitive axioms; it is not a complete private-body
census or a substitute for the separate release proof check.

An ordinary supplementary module check is:

```sh
lake env leanchecker --verbose MultivariatePolynomials.IdealOfVars MultivariatePolynomials Test.IdealOfVars Test.Axioms Test.LeafImport Test.ReadmeExample
```

Exact revision-specific review records retain complete raw/private declaration
and stored-body evidence, selected lint results and resource measurements. An
ordinary module check alone is not a full import-trust audit. Headers credit the
project without inventing a copyright owner; private test modules and intentional

mathlib cache was fetched into the new checkout before the six project modules

illustrative expectations for this small project, not a hardware-independent
guarantee, a regression comparison or a claimed speedup. Network/cache state,
